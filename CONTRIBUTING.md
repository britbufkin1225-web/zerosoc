# Contributing to ZeroSOC

Thank you for your interest in contributing to ZeroSOC.

ZeroSOC is a lightweight cybersecurity monitoring dashboard built as a backend and cybersecurity portfolio project. Contributions should improve the project’s reliability, security, documentation, or usability.

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting features
- Improving documentation
- Fixing backend issues
- Improving dashboard behavior
- Reviewing API behavior
- Improving security checks or logging

## Before You Start

Before making changes:

1. Check the existing issues.
2. Create or comment on an issue if the change is significant.
3. Fork the repository or create a new branch.
4. Keep changes focused and easy to review.

## Development Guidelines

- Keep backend route behavior consistent.
- Use clear and readable code.
- Avoid committing secrets, API keys, tokens, passwords, or `.env` files.
- Keep API responses structured and consistent.
- Update documentation when changing visible behavior.
- Add or update screenshots if dashboard changes affect the README.
- Test affected endpoints or dashboard features before opening a pull request.

## Pull Request Checklist

- [ ] The project starts without errors
- [ ] Affected backend routes were tested
- [ ] Dashboard changes were checked in the browser
- [ ] No secrets or local-only files were committed
- [ ] Documentation was updated if needed
- [ ] Screenshots were updated if needed

## Security Issues

Do not open public issues for security vulnerabilities. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
